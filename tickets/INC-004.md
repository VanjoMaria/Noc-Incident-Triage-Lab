# INC-004: Router Link Failure — OSPF Reroute Over Backup Path

**Lab:** Lab 2 — STP-OSPF Redundancy Lab
**Severity:** Sev3 — planned failover validation test, backup path present (full router mesh)
**Status:** Resolved automatically by OSPF — no manual intervention required

| Field | Detail |
|---|---|
| Symptoms | None expected for end-to-end reachability. Router3's direct link to Router4 (`10.254.1.0/30`, Gig0/0) shut down deliberately to test failover. |
| Diagnostic Steps | `%OSPF-5-ADJCHG ... FULL to DOWN` logged immediately on both Router3 and Router4. `show ip ospf neighbor` confirmed only the Router1 adjacency remained on each side. `show ip route` showed the direct-cost-2 path replaced by a cost-3 path via Router1 on both ends. |
| Root Cause | N/A — deliberate fault injection to validate redundancy, not a misconfiguration. |
| Resolution | No manual action needed — OSPF automatically recalculated and installed the surviving path via Router1. No loss of reachability between Site A and Site B at any point. |
| Time to Recover | Under 35 sec. Fault logged at elapsed sim time ~25:08:30; by ~25:09:05 Router4's `show ip ospf neighbor` already showed a live FULL/BDR adjacency with an active, counting-down dead-timer over the backup path. |
| Prevention | The full 3-router mesh (rather than a single WAN link) is what made this a non-event — a single-homed WAN design would have made Site B fully unreachable instead of just taking a longer path. |

## Evidence

**Fault (Router3):**
```
Router(config)#int g0/0
Router(config-if)#shutdown
%OSPF-5-ADJCHG: Process 100, Nbr 192.168.4.1 on GigabitEthernet0/0 from FULL to DOWN,
Neighbor Down: Interface down or detached
```

**After — Router3:**
```
show ip ospf neighbor
10.254.1.9   1   FULL/BDR   10.254.1.9   GigabitEthernet0/1

show ip route
O   192.168.4.0/25 [110/3] via 10.254.1.9, GigabitEthernet0/1
```

**After — Router4:**
```
show ip ospf neighbor
10.254.1.9   1   FULL/BDR   10.254.1.6   GigabitEthernet0/2

show ip route
O   192.168.4.128/25 [110/3] via 10.254.1.6, GigabitEthernet0/2
```
